# 📜 Developer Skill Codex: Sovereign AI IDE

## 🎯 Visi Penguasaan
Membangunkan keupayaan untuk membina sistem yang **setanding Senior Developer** dengan mengutamakan kualiti kod, modulariti, dan kecerdasan buatan (AI) yang berjalan secara lokal sepenuhnya.

---

## 🛠️ Tech Stack & Mastery Roadmap

### 1. Linux & Local AI Infrastructure (The Engine)
Fokus kepada penyediaan persekitaran yang stabil untuk "otak" AI.
- [ ] **WSL2 (Ubuntu) Proficiency:** Kemahiran menguruskan *distro* Linux, mengawal sistem fail lintas-OS (Windows-Linux), dan mengoptimasi penggunaan RAM melalui fail `.wslconfig`.
- [ ] **Ollama Deployment:** Pemasangan model bahasa lokal (LLM) dan konfigurasi `OLLAMA_ORIGINS` untuk akses API tanpa sempadan (CORS).
- [ ] **Hardware Acceleration:** (Fokus RTX 3060Ti) Implementasi **NVIDIA Container Toolkit** di WSL2 untuk memastikan AI diproses oleh GPU (VRAM), bukan CPU.
- [ ] **Model Selection & Quantization:** Memahami perbezaan antara model (CodeLlama, DeepSeek, Phi-3) dan cara menggunakan format **GGUF** untuk efisiensi RAM.

### 2. Frontend Engineering (The Interface)
Membina antaramuka yang laju, estetik, dan tidak membebankan pelayar web (Chrome).
- [ ] **CSS Grid & Flexbox Mastery:** Mencipta layout modular yang responsif tanpa menggunakan *framework* luar yang berat.
- [ ] **Glassmorphism & Apple-Aesthetics:** Implementasi kesan `backdrop-filter`, saturasi, dan transisi lancar dengan beban GPU yang minima.
- [ ] **Vanilla JavaScript (ES6+):** Manipulasi DOM secara langsung untuk kelajuan maksimum.
- [ ] **Iframe Communication:** Menguruskan "Hot-Reload" antara editor dan preview pane menggunakan `srcdoc` atau `blob URL`.

### 3. Logic & AI Bridge (The Intelligence)
Jambatan komunikasi antara input pengguna dan jawapan AI.
- [ ] **Asynchronous Programming:** Penguasaan `async/await` dan `fetch` untuk memanggil API AI secara *non-blocking*.
- [ ] **Debounce Logic:** Teknik menangguhkan fungsi (seperti auto-save/render) untuk menjimatkan kitaran CPU semasa pengguna sedang menaip rancak.
- [ ] **Semantic Compression:** Teknik menghantar segmen kod yang kecil kepada AI (Modular Prompting) untuk mendapatkan kualiti "polish" yang lebih tinggi.
- [ ] **Regex & Syntax Analysis:** Penggunaan *Regular Expressions* asas untuk mengesan ralat kod secara manual sebelum dihantar ke AI (Pre-processing).

### 4. Automation & Workflow (The Orchestration)
Menggunakan PowerShell untuk memudahkan pengurusan harian.
- [ ] **PowerShell 7 Scripting:** Membina skrip `.ps1` untuk melancarkan keseluruhan *stack* (WSL + Ollama + Local Server) dengan satu klik.
- [ ] **Background Process Management:** Menggunakan `Start-Process` dengan parameter tersembunyi untuk menjaga kekemasan ruang kerja Windows.

---

## 🚀 Strategi "Iterative Polish" (Senior Level)
Untuk mencapai hasil setanding developer profesional pada laptop 8GB:
1. **Pecah & Perintah:** Jangan minta AI buat sistem besar; minta AI *polish* fungsi kecil (10-20 baris).
2. **Re-prompting:** Jangan terima hasil pertama. Beri teguran (e.g., *"Make it more modular"*) untuk hasil yang lebih bersih.
3. **Manual Review:** Gunakan AI sebagai pembantu, tetapi pastikan logic akhir adalah dari pemahaman anda sendiri.
